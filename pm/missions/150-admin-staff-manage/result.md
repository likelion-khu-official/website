# 결과 — #150 BE · 운영진 소개 관리 — 운영진 카드를 만들고 고치는 화면

> 미션이 닫힐 때 채운다. 재사용할 통찰은 pm/docs/learnings.md로 졸업.

## 산출물
- [PR #316](https://github.com/likelion-khu-official/website/pull/316) — `/admin/staff`에 운영진 카드 추가·수정·삭제·드래그 정렬·공개 여부·일괄 저장과 데스크톱/모바일 미리보기를 구현했다.
- 랜딩과 관리 화면이 `StaffShowcaseCard`를 공유하고, 사진은 원형 가이드에서 위치·배율을 조정해 1:1 WebP로 자른 뒤 기존 OCI 업로드 경로를 사용한다. 백엔드 수정 계약도 이름·학과·입학연도까지 넓혔다.
- 남은 구멍: 미션 Done의 “멤버 명단에서 운영진 지정”은 구현되지 않았다. 현재도 카드 폼에 이름·학과·입학연도를 직접 입력하며 `Staff`와 `Member`가 연결되지 않는다. PR 본문에 명시된 대로 자동 QA도 실행하지 않았다.

## 결정
- 편집 중 변경은 초안으로 모아 저장 버튼 한 번에 반영한다. 정렬·여러 카드 편집을 하다가 일부만 서버에 반영되는 상태를 줄이기 위해서다.
- 실제 랜딩 카드 컴포넌트를 미리보기에도 재사용했다. 관리 화면과 공개 결과가 따로 진화하는 시각적 drift를 막기 위해서다.

## 배운 것
- 풍부한 편집 경험이 만들어져도 원래 진입점인 “기존 멤버를 지정한다”가 빠지면 스펙은 완결되지 않는다. 화면 완성도와 Done 충족 여부를 별도로 대조해야 한다.
