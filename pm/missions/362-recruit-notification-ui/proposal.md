# 제안 — #362 모집 알림 신청 UI 개선

> 이슈: https://github.com/likelion-khu-official/website/issues/362 · 담당 김우진(@xhae123)

## 왜

현재 이메일 입력과 개인정보 고지가 서로 떨어진 박스처럼 보여 한 작업으로 읽히지 않는다. 필수 고지를 숨기거나 줄이지 않으면서도 입력→고지 확인→동의→신청 순서를 명확히 해야 한다.

## 범위

- 입력과 개인정보 고지를 하나의 신청 패널로 묶는다.
- 이메일 입력에 항상 보이는 라벨을 제공한다.
- 수집 목적·항목·보유 기간·동의 거부 영향을 구조화해 모두 표시한다.
- 랜딩에서는 패널을 닫아 이전 CTA로 돌아갈 수 있게 한다.
- 신청 API와 개인정보 정책은 변경하지 않는다.

## 완료 기준

- 필수 고지와 동의 여부를 명확히 확인할 수 있다.
- 동의 전에는 신청 요청이 전송되지 않는다.
- 성공·실패 상태가 보조기술에도 전달된다.
