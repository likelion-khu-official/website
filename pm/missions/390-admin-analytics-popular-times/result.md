# 결과

관리자가 선택 기간의 방문이 몰린 한국시간대와 요일을 요약 문장과 두 막대그래프로 확인할 수 있게 했다. 실제 페이지 조회 건수를 사용하고 두 축 모두 0부터 시작한다.

## 한국시간 경계 검증

- `2026-08-02T15:30Z` → 한국 `2026-08-03 월요일 00:30`
- `2026-08-03T11:30Z` → 한국 `월요일 20:30`
- `2026-08-04T11:30Z` → 한국 `화요일 20:30`
- API 결과: 0시 1회, 20시 2회, 월요일 2회, 화요일 1회, 합계 3회
- UTC 기준 원래 날짜인 8월 2일을 한국 기간으로 조회하면 0회

## 화면 QA

- 데스크톱 시간대 hover·요일 실제 건수: `evidence/desktop-popular-times-hover.png`
- 390px 모바일 두 분포: `evidence/mobile-popular-times.png`
- QA 데이터에서 시간대·요일 분포 각각의 합이 전체 1,474회와 일치한다.
