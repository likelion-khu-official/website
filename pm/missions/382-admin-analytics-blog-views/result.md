# 결과

관리자가 선택 기간의 블로그 글별 제목·게시일·공개/숨김 상태·조회수를 비교하고, 글 하나를 선택해 날짜별 조회 추이를 볼 수 있게 했다. 선택은 경로 문자열이 아니라 글 ID로 URL에 남는다.

## 실제로 이어진다는 증거

- 글 A 이전 slug 조회 2회 + 변경된 slug 조회 1회 → 같은 불변 글 ID 합계 3회
- 글 B 조회 1회 → 글별 표 3회·1회
- 글 A 제목 변경 → 관리자 표에는 현재 제목, 과거 조회는 그대로 유지
- 글 A 숨김 → 관리자 표에는 `숨김`, 과거 3회와 선택 글 그래프 유지
- #382 배포 전에 경로만 저장된 블로그 조회도 마이그레이션 업그레이드 테스트에서 현재 글 ID로 연결

## 화면 QA

- 데스크톱 선택 글 표·그래프: `evidence/desktop-blog-selected.png`
- 390px 모바일 선택 글 표·그래프: `evidence/mobile-blog-selected.png`
- 모바일에서는 제목 아래 slug·상태·게시일을 묶고 조회수를 오른쪽에 고정해 가로 스크롤 없이 읽는다.
