# 결과

관리자가 선택 기간에 홈의 프로젝트·운영진·블로그·모집 섹션까지 실제로 내려온 방문 수를 가로 막대그래프와 정확한 수치로 비교할 수 있게 했다.

## 실제 HTTP와 DB로 확인한 중복 방지

- 방문 A: 프로젝트를 두 번 보내고 운영진을 한 번 보냄 → 프로젝트 1회·운영진 1회
- 방문 B: 프로젝트를 한 번 보냄 → 프로젝트 총 2회
- 개발 호스트에서 보낸 블로그 도달 → 저장하지 않음
- DB에는 총 3건만 남고 방문자·방문 UUID는 각각 64자 SHA-256 값으로만 저장
- 다른 기간을 조회하면 네 섹션 모두 0회

## 화면 QA

- 데스크톱 막대 hover·정확한 표: `evidence/desktop-section-hover.png`
- 390px 모바일 그래프·표: `evidence/mobile-section-reach.png`
