# 결과

관리자가 선택 기간의 모바일·데스크톱·기타 페이지 조회 비율을 도넛과 정확한 표로 확인할 수 있게 했다. 알 수 없는 기기도 버리지 않으며, 세 분류의 건수는 항상 전체 조회와 같고 표시 비율은 100.0%가 된다.

## 실제 HTTP와 DB로 확인한 분류

- 모바일 User-Agent 조회 2회 → 모바일 2회·50.0%
- 데스크톱 User-Agent 조회 1회 → 데스크톱 1회·25.0%
- 알 수 없는 User-Agent 조회 1회 → 기타 1회·25.0%
- 세 분류 합계 4회 = 전체 조회 4회
- 각 한 건씩 3회인 경우 33.4% + 33.3% + 33.3% = 100.0%
- 조회가 없는 기간은 세 분류 모두 0회

## 정보 최소화

- User-Agent는 수집 요청을 처리하는 순간 세 분류로만 바꾼다.
- DB와 분석 응답에는 `MOBILE`·`DESKTOP`·`OTHER`만 남는다.
- 세부 기기명·모델·OS 버전·원본 User-Agent는 저장하지 않는다.
- 배포 전 기존 페이지 조회는 삭제하지 않고 `OTHER`로 보존한다.
