# 결과 — #146 BE · 명단 열람 — 지원자·구독자 명단을 보는 화면

> 미션이 닫힐 때 채운다. 재사용할 통찰은 pm/docs/learnings.md로 졸업.

## 산출물
- [PR #240](https://github.com/likelion-khu-official/website/pull/240) — `GET /api/admin/recruitment/subscribers`와 어드민 구독자 명단 화면을 추가했다. 이메일·신청 시각을 최근 신청 순으로 보여주고 빈 상태·401·403을 검증했다.
- `shared/types/recruitment.ts`에 `SubscriberSummary` 계약을 남겼다. 지원자 명단은 당시 지원폼 데이터 소스가 없어 범위에서 제외했으며, 이후 지원폼 미션에서 별도로 구현됐다.

## 결정
- 구독자 이메일은 개인정보이므로 공개 모집 상태 API와 분리한 관리자 전용 엔드포인트로만 제공했다.
- 존재하지 않는 지원자 데이터까지 한 화면에 맞추지 않고, 실제 데이터가 있던 구독자 명단만 먼저 끝냈다.

## 배운 것
- 이름이 하나인 “명단” 화면도 데이터 소스·권한·완성 시점이 다르면 억지로 묶지 않는 편이 낫다. 준비된 수직 슬라이스를 먼저 닫아야 검증 가능한 결과가 남는다.
