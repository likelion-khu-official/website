# 블로그 글별 조회수와 추이

## 문제

전체 페이지 조회수만으로는 어떤 글이 실제로 읽혔는지 알 수 없다. 경로 문자열만 저장하면 글 제목이나 slug가 바뀔 때 같은 글의 과거 조회가 둘로 갈라지는 문제도 있다.

## 제안

- 블로그 상세 조회가 들어온 시점에 현재 slug를 글의 불변 ID로 해석해 조회 기록에 함께 저장한다.
- 기존 경로 기반 기록도 마이그레이션 시 현재 글 ID로 연결한다.
- 선택 기간의 글별 제목·게시일·공개 상태·조회수를 표로 보여주고, 글을 선택하면 같은 기간의 추이를 표준 선 그래프로 보여준다.
- 숨긴 글도 목록과 과거 조회에서 지우지 않는다. 운영자는 “지금 공개됐는가”와 “과거에 읽혔는가”를 함께 봐야 하기 때문이다.
- 선택 글 ID는 URL에 남긴다.

## 검증

- 글 A 2회, 글 B 1회 조회가 DB의 불변 글 ID와 글별 집계 2·1회로 이어지는지 확인한다.
- 글 제목과 slug를 바꾼 뒤 새 경로 조회를 추가해도 같은 글 ID 합계로 이어지는지 확인한다.
- 글을 숨긴 뒤에도 과거 합계와 숨김 상태가 관리자 응답에 남는지 확인한다.
- 데스크톱·모바일 표와 선택 글 그래프를 브라우저에서 확인해 PR에 첨부한다.
