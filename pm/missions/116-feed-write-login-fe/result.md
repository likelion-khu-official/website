# 결과 — #116 FE · 글쓰기 화면(링크 없이 바로 쓰기)

> 미션이 닫힐 때 채운다. 재사용할 통찰은 pm/docs/learnings.md로 졸업.

## 산출물
- [PR #144](https://github.com/likelion-khu-official/website/pull/144) — 글쓰기 경로를 `/blog/write`에서 `/member/write`로 옮기고, 매직링크·작성자 선택을 제거해 로그인 세션의 이름을 작성자로 표시했다.
- 로그인하지 않았으면 `/member/login?returnTo=...`로 보낸 뒤 로그인·첫 비밀번호 변경 후 원래 글쓰기 화면으로 돌아온다. 제출부터 즉시 게시까지 실제 세션으로 종단 확인했다.

## 결정
- `returnTo`는 `/`로 시작하되 `//`로 시작하지 않는 내부 경로만 허용했다. 로그인 복귀 편의를 유지하면서 외부 사이트로 보내는 오픈 리다이렉트를 막기 위해서다.
- 작성자 정보는 클라이언트가 고르거나 보내지 않고 `/api/member/auth/me`의 세션 주체만 사용했다.

## 배운 것
- 인증 전환은 폼만 바꾸는 일이 아니다. 진입 경로·API 헤더·로그인 복귀·권한별 오류 화면까지 한 흐름으로 걷어내야 옛 인증 방식이 남지 않는다.
