# 결과 — #151 BE · 모집 관리 — 모집을 켜고 끄는 화면

> 미션이 닫힐 때 채운다. 재사용할 통찰은 pm/docs/learnings.md로 졸업.

## 산출물
- [PR #156](https://github.com/likelion-khu-official/website/pull/156) — `/admin/recruitment`에서 모집 상태·구독자 수를 보고 모집을 켜고 끄며, 켜기 전 발송 인원을 확인하고 공개 화면을 미리보는 관리 흐름을 만들었다.
- 방문자용 `GET /api/recruitment/status`를 추가해 랜딩과 `/recruit`가 평소 구독 폼과 모집 중 안내를 실제 서버 상태로 전환하게 했다. 지원폼 준비 전 prod 모집 시작을 막는 환경 스위치도 함께 뒀다.

## 결정
- 공개 응답에는 `{open}`만 두고 구독자 수는 관리자 API에만 남겼다. 방문자가 화면 상태를 아는 데 운영 지표까지 필요하지 않기 때문이다.
- 지원폼이 없던 시점에는 임시 모집 안내를 보여주고, 폼 완성 뒤 교체할 수 있게 공개 상태와 화면 표현을 분리했다.

## 배운 것
- 관리자용 상태 조회를 그대로 공개 화면에 재사용하면 인증을 풀거나 불필요한 운영 정보까지 노출하게 된다. 같은 상태라도 소비자별 최소 응답을 따로 두는 편이 안전하다.
