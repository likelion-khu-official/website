# 작업 로그

- Plausible·Grafana·Vercel Web Analytics·Apache ECharts 공식 문서에서 기간 선택, 상위 페이지, 툴팁, 확대, 익명 집계 방식을 확인했다.
- Vercel 맞춤 이벤트는 Pro·Enterprise 요금제에 한정되어 전체 분석 기반으로 쓰지 않기로 했다. 요금제나 외부 API 토큰 없이도 저장 증거를 만들 수 있도록 1차 데이터는 우리 백엔드가 익명으로 수집한다.
- 공개 조회 3회를 실제 HTTP로 보낸 뒤 DB 3행, 관리자 합계 3회, 페이지별 2회·1회로 이어지는 통합 테스트를 만들었다. 기간 밖 조회와 운영 외 호스트·내부 경로·봇 제외도 같은 경계에서 검증했다.
- 그래프는 Apache ECharts의 SVG 렌더러와 axis tooltip·dataZoom을 사용했다. Grafana처럼 관측점을 직선으로 잇고, 마우스를 올린 날짜의 정확한 값과 교차선을 함께 보여준다.
- 첫 모바일 캡처에서 조회수 열이 가로 스크롤 뒤에 숨은 것을 확인했다. 모바일 표를 페이지명·경로 묶음과 조회수 두 열로 바꿔 390px에서도 핵심 숫자가 바로 보이게 수정했다.
- 전체 BE 테스트 387개 중 Docker가 없는 환경에서 Mailpit 기반 기존 통합 테스트 8개만 초기화 실패했다. BE unit shard와 분석·마이그레이션 통합 테스트, FE 85개 테스트·lint·build, 분석 Playwright 2개는 통과했다.
