# 제안 — #360 블로그 목록 UI 개선

> 이슈: https://github.com/likelion-khu-official/website/issues/360 · 담당 김우진(@xhae123)

## 왜

현재 목록은 큰 소개 문구와 카드 그리드가 블로그 글을 빠르게 훑는 일을 방해한다. 앞으로 글이 계속 늘어날 예정이므로 현재 글 수에 맞춘 예외 레이아웃보다, 제목·요약·작성자·날짜를 같은 축에서 비교할 수 있는 확장 가능한 목록이 필요하다.

## 범위

- 소개 영역을 짧게 줄이고 기록 목록을 첫 화면 가까이 배치한다.
- 랜딩과 전체 목록 모두 글 하나가 가로 한 행을 차지한다.
- 썸네일·제목·요약·작성자·날짜를 모든 글에서 같은 위치에 둔다.
- 모바일에서는 행 구조를 유지하고 썸네일과 타이포그래피만 축소한다.

## 완료 기준

- 게시물 수와 썸네일 유무에 관계없이 안정적으로 표시된다.
- 제목·요약·작성자·날짜를 빠르게 훑을 수 있다.
- 모바일과 데스크톱에서 상세 글 링크의 클릭 영역이 충분하다.
- 상세 페이지는 변경하지 않는다.
