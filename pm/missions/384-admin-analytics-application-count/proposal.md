# 평시에도 유지되는 지원 수

## 문제

지원 수를 분석 화면의 최근 30일 조건으로 세면 모집 종료 후 시간이 지날수록 0이 된다. 운영자가 필요한 값은 조회 기간의 트래픽이 아니라 현재 모집, 또는 가장 최근에 끝난 모집에 실제 접수된 최종 지원 수다.

## 제안

- 모집을 열 때마다 불변 모집기 ID와 시작 시각을 만들고, 지원서를 접수할 때 그 ID만 함께 저장한다.
- 모집을 닫으면 종료 시각을 기록하되 최근 모집기 ID는 유지한다. 새 모집을 열 때만 새 ID와 0건으로 전환한다.
- 분석 API는 지원자 답변을 읽거나 반환하지 않고 모집기 ID별 행 개수만 센다.
- 분석 화면 맨 위에 지원 수 카드 하나만 두고, 모집 중인지 최근 종료 모집인지와 기간을 쉬운 말로 보여준다.
- 이 카드는 아래 트래픽 기간 선택과 분리한다.

## 검증

- 첫 모집 중 2건 접수 → 카드 2건
- 첫 모집 종료 → 같은 모집기 2건과 종료 기간 유지
- 새 모집 시작 → 새 모집기 0건으로 전환
- 새 모집에 1건 접수 → 카드 1건
- 분석 JSON과 화면에 이름·답변·폼 스키마가 없는지 확인
