# 작업 로그

- 클릭을 성공 건수처럼 보이지 않게 화면 하단에 “관심 신호이며 실제 접수·신청 성공과 다를 수 있다”고 명시했다.
- 이벤트 키는 클라이언트가 임의 문자열을 보내는 구조가 아니라 서버 enum 허용 목록으로 제한했다. 일반 DOM·URL 토큰·이메일 같은 값이 분석 데이터에 들어갈 통로를 줄이기 위해서다.
- 같은 지원 흐름도 랜딩의 시작 클릭과 지원서 화면의 제출 클릭을 위치로 나눴다. 어느 진입점에서 행동이 발생했는지 운영자가 구분할 수 있다.
- Grafana·제품 분석 화면에서 익숙한 선 그래프 hover, 행동 필터, 정확한 위치별 표를 함께 사용했다.
