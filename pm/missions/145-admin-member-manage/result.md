# 결과 — #145 BE · 멤버 관리 — 부원 계정을 발급·관리하는 화면

> 미션이 닫힐 때 채운다. 재사용할 통찰은 pm/docs/learnings.md로 졸업.

## 산출물
- [PR #155](https://github.com/likelion-khu-official/website/pull/155) — `/admin/members`에서 부원 등록·목록·수정·비밀번호 초기화·오프보딩을 처리하는 풀스택 관리 화면을 만들었다.
- `GET /api/admin/members`와 `POST /api/admin/members/{id}/offboard`를 추가하고, `Member.offboardedAt` 기반 소프트 삭제·로그인 차단·계약 타입·마이그레이션·블랙박스 QA 기록을 남겼다.

## 결정
- 오프보딩은 행을 지우지 않고 로그인만 막는다. 부원이 남긴 글·프로젝트·기록을 보존해야 하기 때문이다.
- 멤버 등록·수정·초기화·오프보딩은 위키 권한에 맞춰 모든 `ADMIN`의 공용 업무로 통일했다.

## 배운 것
- 계정 인증이 구현돼도 발급·초기화·퇴장 화면이 없으면 운영상 로그인 기능은 존재하지 않는 것과 같다. 계정의 전체 생애주기를 관리 표면까지 이어야 한다.
