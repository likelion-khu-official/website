# 결과

관리자가 선택 기간의 프로젝트별 제목·기수·공개/숨김 상태·조회수를 비교하고, 프로젝트 하나를 눌러 날짜별 조회 추이를 볼 수 있게 했다. 제목을 바꾸거나 숨겨도 조회는 URL 문자열이 아니라 프로젝트 ID에 이어진다.

## 실제로 이어진다는 증거

- 프로젝트 A HTTP 조회 2회 + 제목 변경 뒤 HTTP 조회 1회 → 같은 프로젝트 ID 합계 3회
- 프로젝트 B HTTP 조회 1회 → 별도 프로젝트 ID 합계 1회
- 프로젝트 A 숨김 → 관리자 표에는 현재 제목·`숨김` 상태와 과거 3회 유지
- #383 배포 전에 경로만 저장된 `/projects/{id}` 조회도 migration 업그레이드 테스트에서 프로젝트 ID로 연결
- 선택 기간을 API에 적용하고, 프로젝트를 선택하면 같은 기간·간격으로 표와 그래프를 함께 조회

## 화면 QA

- 데스크톱 프로젝트 표·선택 그래프: `evidence/desktop-project-selected.png`
- 390px 모바일 프로젝트 표·선택 그래프: `evidence/mobile-project-selected.png`
- 모바일에서는 기수와 공개 상태를 제목 아래에 묶고 조회수를 오른쪽에 고정해 가로 스크롤 없이 읽는다.

## 자동 검증

- FE 24개 파일, 87개 테스트·lint·프로덕션 build 통과
- Playwright 프로젝트 데스크톱·390px 시나리오 통과
- BE unit shard 단독 재실행 통과
- 프로젝트 HTTP→불변 ID 저장→집계, 기존 경로 backfill, 전체 Flyway→Hibernate 스키마 일치 통합 테스트 통과

참고로 처음 BE unit·통합 테스트를 동시에 실행했을 때 같은 Gradle XML 결과 경로가 충돌했다. 기능 실패가 아니며, 통합 테스트와 unit shard를 각각 단독으로 다시 실행해 둘 다 통과시켰다.
