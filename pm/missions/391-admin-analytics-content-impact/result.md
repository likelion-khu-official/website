# 결과

관리자가 선택 기간에 공개한 블로그·프로젝트를 골라 최초 공개일, 사이트 전체·해당 콘텐츠 조회 추이, 같은 길이의 전후 합계를 한 화면에서 비교할 수 있게 했다.

## 실제 DB 비교 검증

- 블로그 최초 공개일: 2026-07-20 10:00
- 제목을 `처음 제목`에서 `바뀐 제목`으로 수정해도 최초 공개일 유지
- 공개 전 7일 사이트 조회 2회, 공개 후 7일 5회
- 공개 후 해당 블로그 조회 3회
- 14개 날짜 시계열의 8번째 점이 정확히 공개일 7월 20일
- 공개 이틀째 프로젝트는 전후 2일씩 비교하고 `complete=false`, 시계열 4일

## 화면 QA

- 데스크톱 공개일 세로선·두 선 hover·7일 완료 비교: `evidence/desktop-content-impact-hover.png`
- 390px 신규 프로젝트 3일 진행 중 비교: `evidence/mobile-content-impact-progress.png`
- 변화율과 함께 “콘텐츠 하나의 효과라고 단정할 수 없다”는 해석 경계를 표시한다.

## 자동 검증

- FE 29개 파일, 98개 테스트 통과(공개일 마커·두 시계열·URL 콘텐츠 선택·완료/진행 상태 포함)
- BE 최초 공개일·불변 ID·제목 수정·동일 기간 합계·신규 진행 중·인증 통합 테스트 통과
- FE 전체 테스트·lint·프로덕션 build 통과
- BE unit shard 통과
- 누적 분석 Playwright 12개 전체와 데스크톱 hover·콘텐츠 전환·390px 모바일 통과
