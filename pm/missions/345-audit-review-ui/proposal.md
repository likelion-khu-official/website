# 감사로그 조사 화면 개편

## 문제

현재 화면은 좁은 타임라인과 행별 원문 펼치기 방식이라 여러 사건을 비교하기 어렵고, 요청 경로·상태 코드·IP·대상 같은 운영 맥락이 화면에서 빠져 있다. 필터도 URL에 남지 않아 새로고침하거나 조사 조건을 공유하면 처음부터 다시 만들어야 한다.

## 제안

- 목록을 시간·결과·사건·행위자·대상을 비교하는 표로 바꾼다.
- 사건을 선택하면 전체 DTO와 필드별 변경 전후를 우측 상세 패널에서 보여준다.
- 주요 활동·전체·로그인 실패·민감 열람 빠른 보기와 기간·행위자·영역·행위·대상·결과 필터를 제공한다.
- 조사 조건과 페이지를 URL에 보존한다.
- 작은 화면에서는 핵심 열을 한 셀에 합치고 상세 패널을 전체 화면으로 전환한다.
- 성공·실패는 색뿐 아니라 텍스트로 표시하고, 시간대와 오류·빈 결과·로딩 상태를 명시한다.

## 완료 기준

- 표와 상세 패널에서 사건을 연속으로 조사할 수 있다.
- DTO의 운영 맥락 필드가 상세 화면에 빠짐없이 나온다.
- 같은 대상의 전체 이력으로 이동할 수 있다.
- URL에서 필터가 복원되고 빠른 보기가 API 조건과 일치한다.
- 키보드로 사건 선택·상세 닫기·필터 조작이 가능하다.
- 컴포넌트 테스트, 린트, 프로덕션 빌드가 통과한다.
