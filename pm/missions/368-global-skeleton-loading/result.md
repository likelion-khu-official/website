# 결과 — #368 FE · 전역 로딩 스켈레톤 적용

> 미션이 닫힐 때 채운다. 재사용할 통찰은 pm/docs/learnings.md로 졸업.

## 산출물
- [PR #370](https://github.com/likelion-khu-official/website/pull/370) — 공용 `Skeleton`·`AdminLoading` 프리미티브를 만들고 프로젝트 목록/상세·멤버·블로그 목록/상세와 관리자 9개 화면의 빈 화면·맨텍스트 로딩을 구조적 스켈레톤으로 교체했다.
- 스켈레톤은 스크린리더에서 숨기고 로딩 컨테이너에 `role="status"`를 부여했다. `prefers-reduced-motion`에서는 펄스를 끄며, 타입체크·lint·72개 테스트·프로덕션 빌드를 통과했다.

## 결정
- 각 스켈레톤은 대응 화면의 컨테이너 폭·헤더·그리드를 그대로 따른다. 공용 회색 박스만 반복하면 로딩이 끝날 때 레이아웃 점프를 줄이지 못하기 때문이다.
- 이미 스켈레톤이 있는 부원 대시보드와 짧은 인증 확인 문구는 범위에서 제외했다.

## 배운 것
- 스켈레톤의 품질은 애니메이션보다 실제 콘텐츠와의 구조 정합으로 결정된다. 없는 카드나 다른 폭을 예고하는 스켈레톤은 체감 속도를 높이기는커녕 전환을 더 불안정하게 만든다.
