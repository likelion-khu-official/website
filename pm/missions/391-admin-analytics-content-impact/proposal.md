# 새 콘텐츠 공개 전후 조회 변화

## 문제

운영자가 블로그 글·프로젝트 공개 뒤 사이트 이용이 달라졌는지 보려면 날짜를 직접 맞춰 여러 그래프를 비교해야 한다. 공개 직후 며칠밖에 안 지난 콘텐츠를 완성된 7일 비교처럼 보이거나 전후 변화만으로 콘텐츠 효과라고 단정하는 위험도 있다.

## 제안

- 선택 기간에 최초 공개된 블로그·프로젝트를 불변 콘텐츠 ID와 최초 공개 시각으로 제공한다.
- 콘텐츠를 고르면 공개 전 7일과 공개일부터 7일의 사이트 전체 조회를 비교한다.
- 공개 후 7일이 지나지 않았으면 현재 지난 일수만큼 전후 기간을 똑같이 줄이고 “비교 진행 중”으로 표시한다.
- 같은 그래프에 사이트 전체 조회, 해당 콘텐츠 조회, 정확한 공개일 세로선을 함께 둔다.
- 제목이 바뀌어도 현재 제목만 갱신하고 최초 공개 시점·과거 조회는 같은 ID에 유지한다.
- 화면에 전후 변화는 상관관계이며 콘텐츠 하나의 효과라고 단정할 수 없다고 명시한다.

## 검증

- 공개일 앞 7일 2회·뒤 7일 5회와 콘텐츠 자체 3회를 정확히 집계
- 제목 수정 뒤에도 최초 공개일과 불변 ID 비교가 유지
- 공개 이틀째 프로젝트는 전후 2일씩, 진행 중으로 표시
- 그래프 공개일 위치가 시계열의 정확한 날짜와 일치
- 관리자만 API에 접근 가능
