# 프로젝트별 조회수와 추이

## 문제

전체 페이지나 블로그 조회만으로는 어떤 프로젝트가 방문자의 관심을 받는지 알 수 없다. 프로젝트는 블로그와 달리 URL 자체에 불변 ID가 있지만, 숨김 뒤 공개 목록에서 사라져도 과거 관심 기록은 운영자에게 남아야 한다.

## 제안

- `/projects/{id}` 조회를 실제 프로젝트의 불변 ID로 확인해 콘텐츠 조회 기록에 저장한다.
- #383 배포 전에 경로만 쌓인 프로젝트 조회도 migration에서 프로젝트 ID로 연결한다.
- 선택 기간의 제목·기수·공개/숨김 상태·조회수를 표로 보여주고, 프로젝트를 선택하면 날짜별 추이를 같은 패널에서 보여준다.
- 제목이나 표시 정보를 수정해도 과거 조회는 ID 기준으로 이어지고, 숨긴 프로젝트도 표에서 과거 조회와 함께 유지한다.
- 선택 프로젝트 ID는 URL에 남긴다.

## 검증

- 프로젝트 A 2회, B 1회의 실제 HTTP 조회가 불변 ID와 글별 집계 2·1회로 이어지는지 확인한다.
- A의 제목을 바꾸고 1회를 더 조회한 뒤 합계가 같은 ID 3회인지 확인한다.
- A를 숨긴 뒤에도 현재 제목·숨김 상태·과거 3회가 관리자 응답에 남는지 확인한다.
- 데스크톱·390px에서 기수·상태·조회수와 선택 프로젝트 그래프를 확인한다.
