# 제안 — #349 게시글 익명 댓글 UI/UX 개선

## Target

Story [#186 방문자가 익명 댓글을 남긴다](https://github.com/likelion-khu-official/website/issues/186)를 전진시키는 FE Sub-task다.

## Deliverable

- 게시글 상세 하단의 댓글 작성·읽기 화면을 블로그의 편집형 시각 언어에 맞게 개편한다.
- 기존 API 계약을 유지한 채 로딩·재시도·등록 성공·실패와 접근성 상태를 명확하게 만든다.
- 댓글 컴포넌트 단위 테스트로 익명 댓글의 기존 규칙과 새 상호작용을 고정한다.

## Why it matters

익명 댓글은 방문자가 블로그에 참여하는 유일한 공개 상호작용이다. 기능만 연결된 초안 상태를 그대로 두면 댓글이 늘수록 작성 영역이 묻히고, 등록 결과나 오류를 확신하기 어렵다. 새 기능을 늘리지 않고 읽기·작성 흐름을 명료하게 만드는 것이 먼저다.

## Done

- 작성 영역이 목록보다 먼저 발견되고 내용 필수·닉네임 선택의 위계가 명확하다.
- 공개 댓글 수와 가려진 자리표시자가 일관되며 원문은 노출되지 않는다.
- 조회·등록의 로딩, 오류, 재시도, 성공 상태가 시각·보조기기에 전달된다.
- 모바일·키보드·reduced-motion을 포함한 접근성과 기존 50/300자·오래된 순 규칙을 테스트한다.
- 전체 프론트 테스트, lint, build가 통과한다.

## Notes

답글·좋아요·정렬·신고·인증·봇 방지와 backend/shared 변경은 범위 밖이다. 리뷰는 PR에서 진행하며 이슈는 병합될 때 닫는다.
