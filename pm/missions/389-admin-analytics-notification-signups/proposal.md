# 선택 기간의 모집 알림 신청 수

## 문제

모집 알림 버튼 클릭은 관심 표현일 뿐 실제 신청 성공을 뜻하지 않는다. 평소 방문이 다음 모집을 기다리는 관심으로 얼마나 남았는지 보려면 개인정보 동의를 거쳐 DB에 새로 생긴 유효 구독을 세야 한다.

## 제안

- 기존 모집 알림 구독 DB의 생성 시각을 선택 기간·일/주/월 간격으로 집계한다.
- 같은 이메일의 반복 요청과 봇 함정에 걸린 요청처럼 새 행을 만들지 않은 요청은 늘리지 않는다.
- 선택 기간의 합계와 날짜별 선 그래프를 주요 클릭 다음에 배치해 클릭과 성공을 구분한다.
- 분석 응답에는 날짜와 수만 넣고 이메일 주소·구독자 명단은 포함하지 않는다.

## 검증

- 신규 이메일 2개와 같은 이메일 반복 1번 → DB 2건·분석 2건
- 봇 요청은 성공처럼 응답해도 DB·분석 0건
- 다른 기간에는 0건
- 분석 응답에 테스트 이메일 문자열이 없음
- 관리자만 API에 접근 가능
