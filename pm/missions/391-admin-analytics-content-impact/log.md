# 작업 로그

- 비교 창은 기본 7일로 고정하되 신규 콘텐츠는 “현재 지난 날 수”만큼 양쪽을 함께 줄였다. 공개 후 2일을 공개 전 7일과 비교하는 불공정한 숫자를 막기 위해서다.
- 블로그는 최초 `publishedAt`, 등록 즉시 공개되는 프로젝트는 최초 `createdAt`을 기준으로 삼았다. 숨김·재공개·제목 수정 시 기준일이 움직이지 않는다.
- 사이트 전체와 해당 콘텐츠 조회를 한 그래프에 두고 공개일 세로선을 표시했다. 공개 직후 해당 콘텐츠 조회가 전체 변화 중 어느 정도인지 같은 날짜 축에서 읽게 하기 위해서다.
- 변화율 옆에 인과관계가 아니라는 문장을 항상 표시했다. 모집·외부 홍보 같은 다른 사건이 같은 기간에 섞일 수 있다.
