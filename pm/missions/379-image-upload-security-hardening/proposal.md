# 이미지 업로드, 공격에 괜찮은지 배포 전에 끝까지 봐주세요

시현님에게 해결책을 정해 주는 미션이 아니다. 8월 28일 공개 배포를 앞두고 PM에게 남은 걱정 하나를 통째로 맡긴다.

정상 사용자가 큰 사진을 올리는 상황은 걱정하지 않는다. 마음에 걸리는 건 누군가 요청을 반복하거나 이상한 파일을 일부러 보낼 때다. 평소 트래픽은 적어도 공격 요청은 다르고, 업로드한 파일은 서버와 저장소를 거쳐 다시 공개되기 때문이다.

PM이 먼저 본 단서는 실제 이미지인지 확인하는 방식, 반복·누적 업로드, 비정상 해상도, 쓰이지 않고 남은 파일, 공개 제공 경계다. 하지만 이것들이 모두 실제 위험인지, 더 빠진 것은 없는지 PM도 모른다.

그래서 이 목록을 구현 체크리스트로 주지 않는다. 안시현이 이미지가 들어와 공개되고 삭제될 때까지 직접 살펴보고, 실제 위험과 과한 걱정을 가른 뒤 우리 규모에 맞는 방어를 정한다. 백엔드 밖의 일이 필요하면 해당 담당자와 함께 풀되, 마지막에 “왜 이제 배포해도 괜찮은가”를 설명할 수 있을 때까지 이 걱정을 닫는 오너를 맡는다.

검증할 때 지킬 것은 세 가지다.

- 공격 검증은 로컬이나 격리된 stage에서 하고 prod에는 시도하지 않는다.
- 공개 이슈·PR·문서에는 즉시 악용 가능한 재현법이나 운영 인프라 상세를 남기지 않는다.
- 약 20명이 쓰는 사이트에 맞는 방어를 택하고, 정상 이미지 흐름이 깨지지 않았는지 함께 확인한다.
