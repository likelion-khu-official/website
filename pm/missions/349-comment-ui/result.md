# 결과 — #349 게시글 익명 댓글 UI/UX 개선

## 산출물

- 리뷰 PR [#351](https://github.com/likelion-khu-official/website/pull/351) — `dev` 대상, 병합 시 #349 종료.
- 댓글 작성 영역을 목록 앞의 composer로 재구성하고, 댓글 메타·본문·가려진 자리표시자를 훑기 쉬운 편집형 목록으로 정리했다.
- 댓글 컴포넌트 테스트 6개로 초기 조회 경합, 공개 댓글 수, 응답 순서, 가려진 원문 비노출, 등록 성공·실패, 재시도를 고정했다.

## 결정

- 초기 댓글 GET이 끝나기 전에는 작성 fieldset을 비활성화한다. 늦게 도착한 조회 응답이 방금 만든 댓글을 덮는 경합을 가장 단순하게 막기 위해서다.
- 댓글 수는 공개 댓글만 세되, 관리자가 가린 댓글의 위치는 자리표시자로 보존한다. 글 상세의 서버 `commentCount`와 로드 후 숫자를 일치시키면서 대화 흔적은 남긴다.
- 답글·좋아요·정렬 같은 새 기능은 넣지 않고 기존 API 응답 순서를 그대로 보여준다. 이번 목표가 기능 확장이 아니라 현재 경험의 완성이기 때문이다.
- 사용자가 PR을 최종 리뷰 표면으로 지정했으므로 이슈는 미리 닫지 않고 `Closes #349`로 병합 시 닫히게 했다.
