# 결과 — #339 FE · 감사로그 리뷰 표면과 민감 열람 경고

> 미션이 닫힐 때 채운다. 재사용할 통찰은 pm/docs/learnings.md로 졸업.

## 산출물
- [PR #340](https://github.com/likelion-khu-official/website/pull/340) — 어드민 `보안 › 감사 로그`에 읽기 전용 목록·필터·상세 변경 diff 화면을 만들고, 지원자 개인정보를 열기 전 “이 열람은 기록됩니다” 경고를 추가했다.
- 같은 세션에서 확인한 경고를 반복 억제하면서도, 실제 열람 기록은 백엔드가 매 요청마다 독립적으로 남긴다.

## 결정
- 감사 화면에는 수정·삭제 동작을 두지 않았다. 리뷰 표면이 기록 변조 표면으로 바뀌지 않게 하기 위해서다.
- 경고는 보안 잠금이 아니라 사전 억지 장치로 취급했다. 취소 선택과 반복 억제는 UX이고, 보안 기록의 성립 조건은 서버다.

## 배운 것
- 사용자에게 보여주는 경고와 강제할 보안 통제를 같은 관문에 묶으면 UI 우회가 곧 기록 우회가 된다. 경고는 행동을 늦추고, 서버 계측은 우회와 무관하게 사실을 남겨야 한다.
