# 작업 로그

- IP+User-Agent 해시는 여러 사람이 같은 네트워크·기기를 쓰면 합쳐지고 원시 네트워크 정보 처리도 필요해 제외했다. 브라우저가 만든 무작위 UUID를 서버에서 단방향 해시하는 편이 실제 사람을 식별하지 않으면서 반복 조회만 안정적으로 묶는다.
- 선택 기간 합계는 기간 전체의 distinct이고, 그래프 각 점은 그 날짜·주·월 안의 distinct다. 따라서 그래프 점을 더한 값과 기간 합계는 다를 수 있다. 일반적인 제품 분석 도구처럼 기간 도달과 시계열 활성 방문을 구분하기 위해서다.
- ECharts의 축 툴팁은 차트 패널 DOM 밖에 렌더링돼 패널 요소만 캡처하면 증거 이미지에서 사라졌다. 패널을 먼저 화면 안으로 스크롤한 뒤 같은 영역을 페이지 좌표로 캡처해 조회수·순 방문자 두 값이 실제 hover에 함께 나오는 것을 확인했다.
