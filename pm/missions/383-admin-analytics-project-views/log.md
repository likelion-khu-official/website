# 작업 로그

- 프로젝트 상세 경로가 이미 불변 프로젝트 ID를 포함하므로, 수집 시 실제 프로젝트 존재를 확인한 뒤 `PROJECT + id`로 저장하는 방식을 선택했다.
- 프로젝트 A를 2회, B를 1회 연 뒤 A 제목을 바꾸고 1회 더 열었다. 실제 HTTP 수집 행과 관리자 API가 A 3회·B 1회로 일치했고, A를 숨겨도 현재 제목·숨김 상태·과거 조회가 유지됐다.
- 프로젝트 표에서 하나를 선택하면 같은 기간 조건으로 그래프를 다시 조회하고, 선택 ID를 URL에 남기도록 했다. 기간이 바뀌면 표와 그래프 컴포넌트를 함께 갱신한다.
- 데스크톱·390px 시각 회귀에서 기수·공개 상태·조회수와 선택 그래프를 확인했다. 블로그·프로젝트 패널 key 충돌 경고도 발견해 각 패널 namespace를 분리했다.
- 계정과 실행 중인 백엔드 없이도 분석 화면의 고정 데이터를 재현할 수 있도록 시각 회귀 전용 Playwright 설정을 두었다. PR 리뷰 증거가 개발자 개인 환경에 따라 달라지지 않게 하기 위해서다.
