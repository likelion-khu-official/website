# 감사로그 조회·분류 기반

## 문제

현재 API는 큰 행위 분류와 행위자 검색만 제공한다. 이 상태에서는 관리자가 특정 대상의 변경이나 실패 사건을 찾으려면 여러 페이지를 직접 훑어야 하고, 감사로그 화면을 열 때마다 생기는 열람 기록이 중요한 사건을 밀어낸다.

## 제안

- 사람이 쓰는 요약문과 별개인 업무 영역 분류를 감사 이벤트에 추가한다.
- 대상 유형·대상 ID·결과·기간·검색어를 함께 적용할 수 있는 조회 계약을 제공한다.
- 주요 활동 보기에서는 감사로그 목록 열람 기록만 숨기고, 전체 보기에서는 원본을 그대로 제공한다.
- 기존 행의 의미 필드는 바꾸지 않고 action·target·path로 새 분류값만 결정적으로 채운다.

## 완료 기준

- shared 타입과 API가 같은 조회 조건을 사용한다.
- 기존·신규 감사기록이 동일한 업무 영역 분류를 갖는다.
- 주요 활동 보기가 민감 열람 등 다른 사건을 숨기지 않는다.
- 마이그레이션 일관성과 핵심 필터 조합이 테스트로 검증된다.
