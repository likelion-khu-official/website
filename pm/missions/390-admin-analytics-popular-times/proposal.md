# 방문이 몰린 시간대와 요일

## 문제

운영자가 게시물 공개·모집 안내 시점을 정할 때 방문자가 실제로 사이트를 보는 때를 알 수 없다. 비율만 크게 그리거나 축을 잘라 보여주면 데이터가 적은 시간대를 과장할 수 있다.

## 제안

- 선택 기간의 공개 페이지 조회를 한국시간 0~23시와 월~일로 집계한다.
- 시간대 24개와 요일 7개를 항상 모두 반환해 조회가 없는 구간도 0으로 보인다.
- 가장 많은 시간대·요일을 쉬운 문장으로 먼저 보여주고, 아래에서 두 막대그래프로 비교한다.
- 두 그래프의 축을 0회부터 시작하고 실제 건수를 사용한다. hover에서 정확한 값을 보여준다.
- 표본이 적을 때 최고 막대만으로 게시 시간을 단정하지 말라는 안내를 붙인다.

## 검증

- UTC 일요일 15:30 = 한국 월요일 00:30을 월요일·0시로 집계
- 한국 월요일·화요일 20:30을 각각 해당 요일·20시로 집계
- 24시간·7요일이 모두 반환되고 합계가 전체 페이지 조회와 일치
- 다른 기간은 0건
- 관리자만 API에 접근 가능
