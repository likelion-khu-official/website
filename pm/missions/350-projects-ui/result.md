# 결과 — #350 프로젝트 목록·상세 UI/UX 개선

## 산출물

- 리뷰 PR: [#352](https://github.com/likelion-khu-official/website/pull/352)
- `/projects`의 압축 아카이브 헤더, 모바일 2열·데스크톱 3열 목록, 빈 상태·오류 복구 UI
- 데스크톱 2단·모바일 1단 상세, 다중 이미지 캐러셀과 전체화면 크게보기
- 공개 멤버 프로필 기반 만든 사람 명단과 이전·다음 프로젝트 미리보기
- 프로젝트 카드·목록·이미지·만든 사람 컴포넌트 회귀 테스트

## 결정

- 현재 6개·단일 기수 데이터에는 검색이나 기수 필터를 넣지 않았다. 실제 프로젝트를 더 빨리 보는 것이 이번 문제의 핵심이기 때문이다.
- 대표 이미지는 장식 사진이 아니라 서비스 화면이므로 가로 프레임에서 `object-contain`으로 전체를 보존했다.
- 첫 항목만 크게 강조하지 않고 모든 프로젝트를 균일한 아카이브 그리드에 배치했다. 현재 여섯 개 결과물은 대표작 선정보다 빠른 비교가 더 중요하기 때문이다.
- 데스크톱 캐러셀은 큰 좌우 클릭 영역, 모바일은 스와이프를 주 입력으로 삼고 크게보기는 클릭과 드래그를 8px 이동 기준으로 구분했다.

## 배운 것

- 대표 이미지처럼 입력 URL에 따라 실패 상태를 초기화해야 하는 컴포넌트는 render 중 상태를 맞추기보다 URL을 포함한 `key`로 이미지 경계를 다시 마운트하면 흐름이 단순하고 예측 가능하다.
