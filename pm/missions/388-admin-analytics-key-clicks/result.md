# 결과

관리자가 선택 기간의 주요 클릭을 행동별·위치별 표와 기간 추이 그래프로 확인할 수 있게 했다. 행동 필터를 바꾸면 합계·그래프·표가 한꺼번에 바뀌며 URL에도 조건이 남는다.

## 실제 HTTP와 DB로 확인한 클릭

- 지원하기: 랜딩 모집 2회 + 지원서 화면 1회
- 모집 알림 신청: 랜딩 모집 1회
- 블로그 전체 보기: 3회
- 모든 프로젝트: 1회
- 프로젝트 GitHub: 2회
- 같은 방문 ID로 보낸 총 10번 클릭이 DB 10건으로 남음
- 지원하기 필터 결과는 합계·그래프 3회, 위치 표 2행으로 함께 축소
- 허용 목록 밖 `ANY_DOM_CLICK`과 이벤트 종류가 맞지 않는 키는 400으로 거부

## 데이터 최소화

- 수집 가능한 행동·위치는 서버의 고정 허용 목록 7개뿐이다.
- URL·토큰·버튼 문구·사용자 입력값은 이벤트에 받지 않는다.
- 방문자·방문 UUID 원문은 저장하지 않고 64자 SHA-256 값만 남긴다.
