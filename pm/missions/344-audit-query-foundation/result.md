# 결과

감사로그를 행위자뿐 아니라 업무 영역·대상·결과·기간으로 함께 좁힐 수 있는 조회 기반을 만들었다. 감사로그 목록을 본 기록은 `AUDIT_REVIEW`로 분리되어 주요 활동 보기에서만 제외되고, 전체 보기에서는 계속 확인할 수 있다.

기존 감사기록의 불변성을 해치지 않도록 원본 의미 필드는 수정하지 않았다. 새 `event_type`은 이미 저장된 action·targetType·path에서 다시 계산 가능한 파생값이며, 신규 기록도 같은 분류 함수를 사용한다.

## 검증

- 감사 분류·복합 조회·주요 활동·컨트롤러 단위 테스트 통과
- 기존 감사 행 위에 새 마이그레이션을 적용하는 업그레이드 테스트 통과
- Flyway 전체 적용 후 Hibernate 스키마 일관성 테스트 통과
- BE unit shard, FE 테스트·린트·프로덕션 빌드 통과
- 전체 BE 테스트에서 Docker가 필요한 Mailpit 통합 테스트 8개만 실행 환경의 Docker 부재로 초기화 실패
